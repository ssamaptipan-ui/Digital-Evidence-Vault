🔍 Verify Evidence

Select an evidence file from the vault. The system will decrypt the stored evidence, calculate its current SHA-256 hash, and compare it with the original hash stored in the database.

🔐 SHA-256 Integrity Check

A SHA-256 cryptographic hash is used to create a unique fingerprint of the evidence file.

🔒 Encrypted Storage

Evidence files are encrypted using Fernet symmetric encryption before being stored.

🛡️ Tamper Detection

If the current hash differs from the original hash, the system detects possible evidence modification.

📋 Audit Trail

Every successful or failed verification attempt can be recorded in the audit log.
